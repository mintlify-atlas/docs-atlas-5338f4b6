## How it works

<Steps>
  <Step title="Open the Actions tab">
    Navigate to your GitHub repository and click the **Actions** tab. GitHub will suggest starter workflows based on your repository's detected languages and tech stack.
  </Step>
  <Step title="Choose a template">
    Browse templates by category — CI, deployments, code scanning, automation, or Pages. Templates matching your stack appear prominently at the top.
  </Step>
  <Step title="Commit the workflow file">
    Click **Configure** on any template to open an editor pre-filled with the workflow YAML. Review it, make any adjustments, then commit it to your repository.
  </Step>
  <Step title="Watch your workflow run">
    GitHub Actions picks up the new file immediately. Your workflow triggers on the next push or pull request (or whichever events are configured in the template).
  </Step>
</Steps>
